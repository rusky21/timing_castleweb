# AGENTS INSTRUCTIONS & CONSTRAINTS

Always strictly follow the design system rules defined in [DESIGN_RULES.md](file:///c:/Users/БОСС/Documents/antigraviti/Castleweb%20v2/DESIGN_RULES.md).

### Non-Negotiable Rules:
1. **Canvas Background:** Strictly achromatic (pure white `#FFFFFF`, neutral light gray `#F5F5F7`, or deep graphite `#0B0B0B`/`#121212`). Never use colored backgrounds (no orange, blue, etc.).
2. **Text Containers:** Hero text and titles must breathe in open space. Never wrap headings or paragraphs in cards, outlines, or containers. Form is created by whitespace and typography.
3. **Geometry:** Only large squircles (`border-radius: 24px - 32px`) or pills (`9999px`). Never use small border-radii (4-12px).
4. **Surfaces:** Solid matte surfaces only. Never use glassmorphism, backdrop-blur, or drop-shadows.
5. **No Visual Clutter:** Strictly no divider lines (`<hr>`), no icons in tiny gray circles, no decorative badges/strokes not present in references.
6. **Self-check:** Always ask "Is everything definitely correct according to the checklist?" before proposing any layout or code.
